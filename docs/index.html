Sha Builder

Free, open-source alternative to Elementor for developers who want direct HTML/CSS/JS control.

Download Latest Release View on GitHub

Features

The speed of a visual builder, without sacrificing code control.

Live preview

Edit HTML, CSS, and JS and see changes instantly in the preview iframe.

Visual element inspector

Hover to inspect, click to select, and edit properties without touching code.

Responsive design

Switch between desktop, tablet, and mobile while you build.

PHP support

Write PHP in the HTML editor, executed on save and render with automatic caching.
